# Preview plan v1: two-creator phone UGC

The 15-second plan below fixes the staging and continuity rules. The character sheets, phone images and selected voice IDs are not attached here, so their appearance and voice assignments remain unverified. I have not inspected or invented them. No scene, speech or video has been generated.

Planning assumptions: vertical 9:16, natural live-action UGC, one simple indoor setting, and the phone as the advertised product. These are reversible choices. Audience, brand, approved benefit and CTA destination are still unspecified, so this treatment uses a claim-free phone reveal. A benefit-led ad needs that product brief before its copy can be finalized. A later 3D preview would help inspect two-person composition, phone orientation and hand contact; its simple proxies would not determine the final visual style.

Success at this stage means three shots totaling exactly 15 seconds, separately bound adult cast members and voices, explicit wardrobe/phone continuity, and an honest reference checklist. Failure would be inventing either person's appearance, substituting a voice, inventing a phone feature, or presenting a plan as a verified render.

## Three-scene directing plan

This proposed grip must be checked against the actual handset and any supplied pose constraints. There is no hidden handoff or action jump between scenes.

## References needed before building the preview

- The two actual character sheets, clearly mapped to CAST-A and CAST-B. Use the supplied adults; do not create replacement identities. Face and body views should be clear enough to recognize each separately. If a sheet lacks a needed angle, identify that gap instead of fabricating it.
- One selected wardrobe reference for each creator. Record garment type, color, pattern, sleeve length, jewelry, glasses, shoes and any visible marks from those references, then freeze those details across all shots. If the selected outfit is already clear in the sheet, a second asset is unnecessary.
- The exact phone's rear and three-quarter/side views, plus case details if applicable. Include model/finish and physical dimensions where known, and a front view if a later revision shows the screen. The current plan deliberately avoids inventing screen UI. Approved screenshots are needed before introducing a screen demonstration.
- The separate selected voice IDs and their providers, explicitly mapped to the two cast IDs. An existing approved sample can help review delivery; producing a new sample is outside this request. No IDs, accents, genders or voice characteristics are inferred from appearance.
- Brand/product brief, audience, one supported benefit if wanted, and the intended CTA destination. The current generic CTA does not assume an offer, URL, price or availability.
- A location reference only if the setting must match a particular place. Otherwise, the neutral set proposal is sufficient for a later blocking preview.

Character sheets serve as identity evidence. Any later crop or conversion into per-person appearance references must preserve the supplied person, be reviewable, and fit the chosen provider's supported inputs. No such crops have been made now. When assets arrive, record their real paths and versions; hash the exact approved assets for a later generation handoff.
