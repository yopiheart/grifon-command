Grifon / Motion review

Make the light count.

Three ways to give Made to move. a visible, deliberate highlight. A is the current implementation direction. B and C are options for review.

One pass. Gold at rest. No looping.

A / Specular pass

Recommended / current

A bright, smooth pass with a crisp white-gold center. Noticeable without taking over the hero; leaves space for the wing reveal.

B / Sharp glint

Quicker / more bite

A narrower, faster highlight with a tighter bloom. Strongest punctuation, but can feel abrupt beside the slower gold arcs.

C / Luminous wash

Broader / slower

A wider light wash lingers across more letters. More luminous overall, with a softer sense of surprise.

Motion study, not a replacement for the live hero. This offline page uses a system serif and SVG light to keep the comparison self-contained; the website uses Instrument Serif. No selection is applied from this page. Reduced-motion visitors see static gold.
