## Oceanides adaptation

Open on one café worker before opening, move into the washroom, point out two
possible places to inspect, then keep both choices visible. Each option is a crop
of the same illustrated room, so the choice feels like a continuation of the
scene. The comments can decide which location the sequel checks first. Any
published outcome should follow the actual vote and a crew-reviewed explanation.

This episode uses local authored SVG/HTML for the room, character and crops, plus
FFmpeg for the portrait proof. Centered white Inter, the transparent Oceanides
mark, and the matte navy palette carry forward the accepted brand direction.
The Saveo footage is reference evidence for a single experiment. Its source
graphics, character, finance narrative and audio stay separate from the pilot.
