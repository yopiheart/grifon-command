# Style-Ref Shoot — shot-list (Grifon-owned raw-ugc library v1)

**Status:** READY TO SHOOT (2026-07-11). Deliverable 2 of the wedge blockers
(`believability_dna.md` → Grill 2). Replaces the brother's scraped SOURCE set
with style refs Grifon owns outright — this library IS the Business-tier look

**Scope: RAW-UGC register ONLY.** Per the approved routing table, only raw-ugc

banked.**

## Who / what / where

- **Cameras:** any recent phone, handheld. NEVER a DSLR, NEVER portrait mode,
  NEVER beauty filter / retouch / HDR-glamour. Ordinary phone defaults.
- **Faces:** anyone with a signed release — Zam, the brother's model, Neil.
  The face gets SWAPPED at generation time, so the person in the style ref
  does not need to be the future presenter; the consent is about the photo +
  the home shown in it, not the identity.
- **Places:** real lived-in PH homes. DO NOT clean the room first — clutter,
  hanging clothes, electric fan, kitchenware = trust signals (t276 evidence).
- **Golden rule:** *mas maganda ang medyo pangit.* Slight blur, grain, harsh
  flash, messy hair are the product. If a take looks "professional," retake it
  worse. (Validated: `8k`/`highly detailed` fragments = +0.0 lift; real-pixel
  imperfection is where the believability lives.)
- **No text/stickers on any shot** — outputs replicate overlay POSITIONS but
  corrupt glyphs; our captions are burned post-render (Surface A). Shoot clean
  plates.
- **Orientation:** vertical, native phone aspect. Leave headroom above the
  face on most shots (caption space).

## Ingest protocol (after shooting)

1. Upload originals to Drive: `GRIFON-STYLE-LIB/raw-ugc/` — originals only,
   no edits, no compression apps.
2. Filename: `ru-<setting>-<shot##>-<take#>.jpg` (e.g. `ru-mirror-07-2.jpg`).
3. One line per FACE in `consent-register.md` (same folder): name, date,
   shots they appear in, release signed Y/N. No release = do not upload.
4. Next session: agent runs the ingest (EXIF strip + manifest + per-shot
   register tagging), then the library plugs into the wedge build.

## Why these 24 and not others

Every family above is either a measured winner from the 279-triplet ingest
(mirror +4.2, flash 81.3, anchored pose 80.0), a weakness that needs ground
truth (dark scenes: lighting = worst dimension at 72.6, outputs over-brighten),
or a beat the B&A skeleton literally casts (before-vibe, after money-shot,
product-in-hand). Nothing here is aesthetic preference — delete a shot only if
its evidence tag no longer holds.
