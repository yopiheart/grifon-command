## 4. Acceptance checklist (agent/Neil runs per submitted set)

- [ ] Signed release photo/scan received BEFORE payment; creator 18+.
- [ ] Originals via Drive (EXIF intact, no Messenger compression).
- [ ] Vertical, no filter/beauty/portrait mode (check EXIF + skin texture).
- [ ] No text/stickers burned in any frame.
- [ ] Assigned shots covered (per style-shoot-shotlist.md families).
- [ ] Lived-in / cluttered scenes (did NOT clean the room into a showroom).
- [ ] At least 3 genuinely dark/low-light frames in the set (the weakest
      dimension needs the most ground truth).
- [ ] Log the creator + shots in `consent-register.md`; file release in
      `GRIFON-STYLE-LIB/consents/`.
- [ ] Pay ₱1,000 GCash; mark set ACCEPTED in the register.
