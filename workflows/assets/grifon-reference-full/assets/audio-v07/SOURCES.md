Only the mixed MP4 auditions are delivered. Raw recordings, isolated stems and
working mixes stay in ignored `sources/` and `work/`, outside the Git backup.

is shipped for these auditions. V05/V06 original synthesis remains separate.

Reproduction: download the listed sources into `sources/` under these basenames:
`close-up.mp3`, `digital-clouds.mp3`, `sweep.wav`, `air-zoom.wav`, `shutter.wav`,
`lens.wav`, `tech-select.wav`, `key.wav`, `bubble.wav`, `gear.wav`.
Run `audio-auditions-v07.py` from this composition with the existing Python/NumPy
runtime. It uses the task's silent V04 picture export, Inter font, FFmpeg and
FFprobe. `source-manifest.json` records downloaded file hashes and license links.
