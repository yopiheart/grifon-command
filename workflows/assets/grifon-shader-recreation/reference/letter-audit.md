# Visible letter and symbol audit

Neil asked whether the isolated letters were intentional after reviewing the
completed visual film. A separate reviewer inspected the actual `c99c93c8`
film's existing native pairs and its bound runtime inputs. No source was edited.

| Character | Native frames | Time in seconds | Purpose |
| --- | --- | --- | --- |
| G | 445-458 | 14.848-15.315 | Cream 3D material |
| R | 459-470 | 15.315-15.716 | Dark gold material |
| a | 471-482 | 15.716-16.116 | Rounded gold material |
| C | 483-495 | 16.116-16.550 | Translucent material |

These are four deliberately cropped glyph/material demonstrations. The source
reference has comparable glyph macros at these intervals. `GRaC` is not a
documented acronym and does not spell `GRIFON`; assigning a meaning to a/C would
be invented. Their unclear semantic connection to the brand is a valid concern.

The binary/slash opener, oval/percent/cross/plus/dash texture reprise, binary
canvas, and incomplete `CREATE ADS` typing state are also intentional. The full
phrase appears by frame 603 / 20.120 seconds. The end mark spells `GRIFON`.

The targeted reviewer inspected paired frames 12, 285, 350, 450, 463, 476, 489,
586, 603, 617 and 668 and checked `full.json`, related shaders and the native
shot map. No accidental standalone text was found in that scope. This is a
targeted letter audit, not a new whole-film visual acceptance gate.
