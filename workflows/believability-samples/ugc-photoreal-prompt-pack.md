# UGC Photo-Real Prompt Pack — Grifon scenes (raw-ugc register, still images)

**What this is:** the 8-block scaffold decoded from the "AI World Cup Edition"
pack ([../believability_dna.md](../believability_dna.md), section "Still-image
raw-ugc scaffold") transplanted to Grifon's actual surfaces: avatar plates,
testimonial stills, storyboard frames, image-ad heroes, organic content.
Ready to paste into any capable image model (Neil verified the source pack on
stills, prompt-only, no reference image). Vertical 9:16 unless noted.

**How to adapt a prompt without breaking it:** swap ONLY the subject (who),
the product (what's in their hands), and the location props (block 6). Never
remove: the smartphone-capture opening, the "not a studio shoot" context, the
optics line, the skin/fabric texture line, the authored imperfections, the
named light source, or the ban tail. Those 7 things ARE the realism — the
World Cup pack varies everything else and keeps exactly those.

**Testing protocol:** generate each prompt on the same model you used for the
World Cup tests, eyeball against those results, note per-prompt verdicts
below each one (`VERDICT:` line). Wins feed the 3rd corroboration + the
Gated Proposal A/B in believability_dna.md.

**Text-in-image rule:** every prompt constrains readable text (same
philosophy as `NO_TEXT_CONSTRAINT`) — headlines/brand copy get composited in
post, never generated.
