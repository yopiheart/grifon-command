## ⛔ ROOT CAUSE — corrected twice, settled on evidence

The 429 was **NOT** quota, **NOT** our rate limiter, and **NOT** scene count.
Two wrong readings were published before the right one; both are recorded here
so the next session does not re-walk them.

| Reading | Why it was believed | Why it died |
|---|---|---|
| ~~Our `TEXT_LIMIT` 30/60s~~ | 429 on `/api/gemini/text` | `Retry-After: 30` is the Google branch ([text.ts:552](../api/gemini/text.ts#L552)); ours sets 60 |
| ~~Google project quota~~ | `RESOURCE_EXHAUSTED` | Every quota row 0%, zero above 90% in 7 days, paid tier 3 |
| ~~10 videos is over a ceiling~~ | 7 runs at ≤9 OK, the one at 10 failed | Capped to 8 → **still 429**. 8 < 9 falsifies it |

**Actual cause, isolated live against production 2026-08-14:**

> Same model, same endpoint, same second — **ZERO video parts returns 200,
> exactly ONE returns 429 `RESOURCE_EXHAUSTED`.**

We hand Gemini the R2 object URL as `fileData.fileUri`
([geminiService.ts:1468](../services/geminiService.ts#L1468)). Gemini only accepts
URIs minted by its own **Files API**. Arbitrary HTTPS URLs were tolerated until
2026-07-31 and stopped working some time before 2026-08-13.

**This blocked the EDL stage of every producer run, for every user** — not just
this pilot. It sat undetected for ~2 weeks because no run was attempted.

### The reproducer (paste in the browser console at grifon.ai, ~$0)

```js
(async () => {
  const k = Object.keys(localStorage).find(x => x.startsWith('sb-') && x.endsWith('-auth-token'));
  const raw = localStorage.getItem(k);
  const tok = (raw.startsWith('base64-') ? JSON.parse(atob(raw.slice(7))) : JSON.parse(raw)).access_token;
  const call = async (label, parts) => {
    const r = await fetch('/api/gemini/text', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + tok },
      body: JSON.stringify({ model: 'gemini-3.6-flash', contents: { parts } })
    });
    console.log(label, r.status, (await r.text()).slice(0, 220));
  };
  await call('0 VIDEO', [{ text: 'Reply with one word: OK' }]);
  await call('1 VIDEO', [{ text: 'Reply with one word: OK' },
    { fileData: { fileUri: '<any R2 scene url>', mimeType: 'video/mp4' } }]);
})()
```

### The shipped mitigation (main, `2a1860b`)

`EDL_MAX_ATTACHED_VIDEOS = 0`. Every scene rides in the prompt as
`videoAttached: no` — a branch the tuned prompt already had, with its own timing
rule (`scriptLine.length / 18`, clamped 3–8s). `sceneBatch` is untouched so the
`scenes-in === scenes-out` passthrough still rewrites every `sourceVideoUrl`.

**Cost: the EDL is blind.** It infers cuts from script length instead of watching
footage. It still passed both gates.

**RESTORE PATH (the #1 open item):** upload each scene video to the Gemini Files
API, pass the returned `files/*` URI, raise the cap. That is the supported
contract and it also survives R2 presign expiry. Restore note lives in the
constant's doc comment.
