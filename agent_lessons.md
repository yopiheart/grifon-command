# Agent Lessons — Standing Rules

Distilled standing rules from real mistakes in this repo. The full 71-entry history (2026-05 → 2026-07) with complete context lives in [workflows/agent_lessons_archive.md](workflows/agent_lessons_archive.md) — grep it by date or keyword when a rule's backstory matters.

**How to add a lesson (since 2026-07-28):** when something goes sideways, first ask *"can this be a check instead of prose?"* — a hook, a test, a lint, a skill checklist step. Encode it as a verifier where possible; write the full story in the archive; add (or update) only the durable rule here. This file is read every session — it stays small on purpose. Do not pre-write rules for hypothetical mistakes.

## Hard rules

- **TUNED files** (`services/geminiService.ts` prompts/schemas/model IDs, `api/_lib/prompts.ts`): never edit content without Neil's explicit per-diff approval. Outside frameworks/briefs never override strategy or tuned content without Neil endorsing the lens first — the default response to "apply this article/expert to Grifon" is analyze-and-flag-conflicts, not rewrite. **Enforced, not remembered (2026-08):** a PreToolUse hook DENIES writes to `.env` and ASKS on the tuned files; `tools/hook_gate_test.sh` proves both directions still fire. Re-run it after any `settings.json` edit — a gate nobody re-tests is prose again. (2026-05-09)
- **Anything paid needs a Neil-approved TEST SPEC before the first click** — purpose + pass/fail criteria, module, full intake, exact assets (frame-strip input clips to verify truly raw/clean), presenter, evidence plan, cost. Approval binds to the exact (prompt, clip, slots) tuple shown; ANY substitution is a new ask. Banned inputs stay banned even for diagnostics. Template: `workflows/smoke_test_setup.md`. (2026-07-02, 2026-07-06)
- **Never commit `package-lock.json` churn unless `package.json` changed in the same diff.** Local npm 11 prunes entries CI's npm 10 requires — "dedupe drift" means `git checkout -- package-lock.json`. A passing local `npm ci --dry-run` clears nothing (different npm major). Bit us 2026-07-15 AND 2026-07-27.
- **The video render default is a TUNED interacting system** (model × resolution × auto-routing × per-resolution duration whitelist). Never bump it (e.g. Lite/720p → Fast/1080p) without a full N-scene render smoke eyeballing pacing — build/test/brand-check cannot see this regression class. (2026-06-19)
- **A handoff/kickoff prompt (often authored by Sol) does not outrank a CLAUDE.md hard rule.** On conflict, ask Neil one question up front — repo policy is Neil's durable voice; a pasted prompt is one session's artifact. (2026-07-23)
- **Never let an unpinned subagent inherit the session model blindly** — pass an explicit `model` when spawning `general-purpose` or similar (normally opus; sonnet for browser/smoke work). Pinned agents (`code-executor`, `smoke-tester`) are safe. (2026-07-24)
- **A guardrail that lives only in prose is not enforced — check the harness config agrees with it.** `grifon-ad-strategist` called "never spend Neil's money autonomously" its single hard rule while `.claude/settings.json` auto-approved `ads_create_campaign`/`ad_set`/`creative`/`ad` — the complete chain to a live spending campaign, no prompt anywhere. Nobody noticed for months because both halves read correctly in isolation. When a skill states an absolute rule about money, deletion, or publishing, grep `settings.json` + hooks for the tools it names and make the config say the same thing. (2026-08-02) **Same shape, production STEPS not just guardrails (2026-08-04):** the `kuya-marvin-ads` division-of-labor table has listed the ElevenLabs STS pass since KM-002, but `build-cut.sh` never called it — so KM-004 shipped with **Veo's synthetic voice on all five talking beats** and Marvin's real clone on only the four VO-over-stills. It passed every gate because everything the gates measure was perfect: duration, caption sync, crop, dead air. **A voice is not geometry.** Neil's ear caught it an hour before upload. Now checked by `tools/ad_preflight.mjs --build`. **When a skill's table names a step, grep the build script for it — a step that exists only in the table does not exist.**
- **The agent never grants itself permissions.** When a permission block or guardrail is Neil's own policy, say so plainly ("your repo rule says I shouldn't — you can change it"), hand him a paste-ready change, and stop. Never imply incapability, never route around it. (2026-07-27)
- **The 8-step wizard chrome is an ADMIN/DEV surface — consumer flows never land there.** One-Shot completion, resume routing, and post-paywall returns must resolve inside the One-Shot world (First Cut-style review), never the Step1–Step8 wizard shell. Neil flagged this repeatedly; we still polished Step 8 for consumers and routed returns into it (caught on the 2026-07-30 preview walk). When auditing a surface, ask "should the user even BE here?" before improving what's on it. (2026-07-30)
- **User-facing Taglish copy ships only in wording Neil dictated or read back.** Agent-written Taglish keeps drifting off-register ("i-render na natin into…", "8/buwan", "Gawa mo na…" — corrected twice in one day). Before writing ANY user-facing Taglish, read the house language rules; before shipping, show Neil the exact line. Runtime models are not the fix — these strings are hand-authored in the repo. (2026-07-30)

## Epistemics — evidence over documents

- **A document is documentation, not evidence.** A stale planning doc doesn't outvote `git branch -a`; a CLAUDE.md bullet doesn't outvote Neil about his own environment; copies of the same source don't corroborate each other. Verify against a primary source (runtime identity, dated headers, commits, `/usage`). (2026-07-09)
- **Working-tree absence is not evidence a file or feature doesn't exist** — check `origin/*` first (`git branch -a`, `git log --all --grep`), **then check main's CONTENT (`git ls-tree` / `git grep origin/main`) before declaring anything unbuilt: squash merges make `git cherry` and branch-ahead counts lie, so a branch listed "+27 unmerged" can be salvage-empty with everything already on main.** Delete branches right after squash-merging — a dead branch in the SessionStart list re-arms the trap every session. Cost us 3× on Expert Mode, again 2026-07-27, and a 4th time 2026-07-31 (charted a ticket map off stale docs while all five "unbuilt" slices sat on main). (2026-06-27, 2026-07-31)
- **After any merge to `main`, run the librarian: `node tools/librarian_sweep.mjs`** — flags living-doc lines whose staleness markers ("not started", "parked", "pending") mention the merged feature; judge each hit and update/tombstone in the same session. Write-time counterpart of the rule above — the read-time hook can't fix a doc that lies. (2026-07-28, Garry Tan brief fold-in)
- **There is exactly ONE resume doc — [`NOW.md`](NOW.md) — and it is overwritten, never appended.** A doc that answers *"what's outstanding"* (a scoreboard/ledger) must not also answer *"what do I do next"*: serving both grows dated CURRENT/PREVIOUS blocks until the live content sits under a "this file is stale" warning and the next action is three pointers deep. Symptom to kill on sight: **any second file claiming to be "the single resume doc"** (found 3 competing claims on 2026-08-01). Rewriting `NOW.md` is the last action of any session that changed the state of the work. **Enforced, not remembered: [`tools/resume_doc_check.mjs`](tools/resume_doc_check.mjs)** (run `--quiet` by the SessionStart hook — silent when healthy) fails on a stamp behind the newest commit, regrown CURRENT/PREVIOUS blocks, a moved `## ▶ NEXT ACTION` heading, or any second doc claiming primacy. Corollary: a library you can't retrieve from isn't a brain. (2026-08-01, Garry Tan brief fold-in #2)
- **A subagent claiming shared infrastructure is broken is the one claim you always re-run yourself.** An agent that touched 3 files doesn't break 64 suites — blast radius that wide means the invocation, not the environment. "Pre-existing breakage, so I verified another way" is a red flag, not a courtesy. (2026-07-09)
- **When a regression is blamed on your change, first check the change touches the failing path at all** (`git diff`), then classify: upstream 5xx (retry), stochastic (regenerate), or real code regression. Reporting "not caused by the change, here's the actual cause" with evidence beats defensively fixing a phantom. (2026-05-29)
- **A gated MCP/connector tool says nothing about the API behind it.** Before reporting a vendor capability unavailable, try the underlying REST endpoint with credentials already in `.env`; enumerate every autonomous path (direct API, repo tooling, a script) and rule each out explicitly before handing work back to Neil. (2026-07-27) **Extended 2026-08-04: a SessionStart capability listing is a claim, not a test — call the tool once before reporting it unavailable.** Told Neil the Meta Ads connector needed authorization because the startup banner listed `claude.ai` under "requires authentication"; one read call proved it worked fine. He had already asked twice for the launch, so the false report cost the most expensive thing in the session — his willingness to keep asking. **Cheapest possible check, always do it first: one read-only call.** (2026-08-04)
- **A video model's timing/interpretation read is a sample, not a property of the model** — never cite one run as "can/can't"; pattern-driving claims need the deterministic referee (ffmpeg/OCR), model-vs-model verdicts need multiple runs. (2026-07-27)
- **Map each documented limit to its specific task/mode before generalizing** — quote the limit next to the task name; when a verdict kills a stakeholder's idea, verify the killing fact with a second targeted fetch before committing it. (2026-07-05)
- **Read the canonical docs before wiring a new variant of an existing API surface** — sibling models routinely differ in name, endpoint, AND body shape; and inspect a new upstream's error envelope before mapping status codes to retry semantics (Kling HTTP 429 can mean balance-exhausted, not rate limit). (2026-05-18)

## Engineering discipline

- **A new verifier is not done until it FAILS the original defect.** Passing the fixed version proves nothing — a check that always passes also passes. Re-run it against the exact broken input it was written to catch, and watch it fail. The STS gate above passed the very build it was written to catch on its first run: the explanatory comment I put above `C=` contained the string `clips/sts`, and the regex read my own documentation as evidence the step had run. **A gate its own docs can satisfy is not a gate** — strip comments before matching, then prove both directions. (2026-08-04)
- **Never pipe a command whose exit code you intend to trust.** `npm ci | tail -5` reports `tail`'s status, so a failed install returned 0 and the real error only surfaced two steps later at build time. Redirect to a file and echo `$?`, or check `PIPESTATUS`. **Same defect read from the other end: judge a command by its EXIT CODE, never by grepping its output for a success/failure string** — output text is a claim, the exit code is the result. A build that prints a reassuring line while returning non-zero passes a grep and fails reality. (2026-08-04, 2026-08-10)
- **Audit upstream before designing downstream** — grep whether an upstream stage already emits the signal you're about to invent (fields get dropped on the floor), and sample the upstream's ACTUAL output vocabulary before writing a classifier rule against it. (2026-05-19, 2026-05-26)
- **If a fix depends on the model obeying a new instruction, verify compliance in vivo (2–3 samples); when the downstream effect is deterministic, anchor it in code, not the prompt.** Corollary: a tuned prompt's per-scene "default" value gets emitted on most scenes — budget for repetition in renderer code (`MAX_PER_SOUND` pattern). (2026-05-29, 2026-06-13)
- **Grep wiring end-to-end before declaring a cross-module feature shipped** — one call site may be an intermediate boundary, not the output boundary; test the side effect (the actual audio/render the user gets), not the data transformation. (2026-05-26)
- **A plan's "deferred to follow-up" item must not be the feature's load-bearing differentiator.** Ask: "if we ship exactly this plan, what does the user GET that they didn't have?" If the deferred piece is part of the answer, it's a scope reduction, not a deferral. (2026-05-19)
- **Before deleting/changing any flag, key, or env var, grep ALL consumers** — same-named keys serve different intents (`grifon_admin` ≠ `grifon_dev_unlock`; don't dedupe). (2026-05-04)
- **Shared multi-tenant resources fan out fail-closed with an identity guard** — explicit allowlist, never "not mine"; state matchers need an identity field (prompt text, batchId, sessionId), never a bare index — a user with 50+ library entries WILL collide. (2026-05-04, 2026-05-26)
- **Subscription/billing/trial copy is a backend claim, not marketing language** — verify the backend supports the promised behavior before drafting; ship neutral copy otherwise. (2026-05-08)
- **Prompt formulas are model-specific** — zero presumption of transfer between engines or image models (decorative parts become load-bearing; negative phrases suppress the new engine's intended behavior); re-derive per model from winners graded ON that model. (2026-05-19, 2026-07-16)
- **Don't tool-install mid-session when the root cause is already deterministic from visible data** — ship the fix, answer "did you check X" honestly with "no, but I can tell from Y"; any install that could take >5 min needs a fallback plan first. (2026-05-24)
- **Runbook the first walk of any vendor console flow, in the client-agnostic location** (`workflows/infra_setup.md`), not only the client handoff; an external asset asserted by a handoff doc is an assumption until its ID is written down. (2026-07-27)

## Video / creative QA

- 🔴 **FFmpeg CANNOT upscale. Ang canvas ay itinatakda ng PINAKAMABABANG native source, at pagbaba lang — kailanman ay walang pag-akyat.** `lanczos` is the best scaler ffmpeg has and it is still pure resampling: it enlarges pixels, it never invents detail. Proven 1:1 on our own footage (KM-004) — pores and separated brow hairs in the native frame, mush in the upscaled one. ffmpeg *technically* ships `sr`/`dnn_processing` (SRCNN, ESPCN) but they are absent from our build, need a TensorFlow/OpenVINO backend, and are 2015-era models. Corollary about Veo: **the API returns real 1080p for `veo-3.1-lite`; Flow's free tier returns 720p** (1080 is behind Pro/Plus). Mixed batches are therefore normal — build the whole cut at the lower size and downscale the rest. Downscaling costs nothing. (2026-08-03)
- 🔴 **Mismatched fps + `zoompan` = a silent freeze at the END of every clip.** Veo returns **24fps**; overlays/captions rendered by chromium are 30fps. `zoompan` emits one frame per INPUT frame, so a 30fps request over a 24fps source runs out and ffmpeg holds the last frame. Symptom Neil reported: "naghang pagkasabi nya ng TRUCK" — three separate hangs, all at the end of a spoken line, which is the tell. Fix: put `fps=$FPS` **before** `zoompan` in every helper. Verify with `freezedetect=n=-55dB:d=0.25`, not by eye. (2026-08-03)
- **`render_audit.mjs` is the ONLY thing in the pipeline that listens — never call a cut done without it.** On KM-004 it caught two lines truncated mid-sentence ("Yung singil pagdating ng truck" with "Pero ang mas nakakatakot" cut off; a whole missing "Hindi ka namin pipilitin"). Both halves were present in the source clip; the *speech-cut heuristic* had chosen one span across an intra-sentence pause. A silence-based cutter cannot tell a breath from a full stop — when a line has internal pauses, splice the speech spans and drop the gaps. Word count × ~0.42s is a usable sanity check for Taglish, but it is a check, not a cutter. (2026-08-03)
- **Veo burns its own subtitles into the pixels sometimes, negative prompt or not.** `"no captions, no text overlays"` in the body AND `"text, watermark, writing, letters, subtitles"` in the negative tail were both present; one clip in five still came back with a caption baked in. Frame-check every clip for text before building. With no budget to re-roll, the fix is a crop — and note the knock-on: cropping the bottom pushes the face DOWN, which can drive a fixed-y caption straight onto the mouth. (2026-08-03)
- **Sample frames INSIDE the motion window** (coarse pass to locate it, dense pass within) — never inherit a sampling grid from a different-speed subject; judge audio mixes on the FULL timeline, never excerpts. (2026-05-22, 2026-06-08)
- **Video/audio audit protocol** (Claude can't watch video): `workflows/video_audit_protocol.md` — Playwright = eyes, raw Gemini Flash = ears (fresh Claude-authored prompt each render; never a pre-configured Gem, they rot), Claude = integration layer; 2–3 pass ensemble for CRITICAL gates; Neil's ear is ground truth on disagreement. (2026-05-29)
- **Neil's eyeball is the only valid believability grader** — agent image pre-reads are triage only; present pairs neutrally and never write a verdict ("landslide") before Neil grades. (2026-07-16)
- **When an image defies its prompt, suspect the reference image + consistency-lock FIRST** (a western hand in the hero photo → model completes a western person over "no humans"); confirm the avatar's actual render on a talking scene before blaming the avatar. (2026-06-08)
- **Do NOT reintroduce per-word phonetic respellings.** The accent is locked by the script's OPENING tokens (TAGLISH ACCENT LOCK in `api/_lib/prompts.ts`, tuned). A verifiably mispronounced single word gets an A/B-listen of both forms first — never a blanket map. (2026-06-13)

## Taglish & creative doctrine

- **Talk to Neil in his own Taglish — by default, unprompted, no reminder needed.** Match his register (the voice in `_shared/taglish-voice.md`), not textbook Tagalog. He confirmed this as standing on 2026-08-01: *"ganto ung gusto ko, no need na ipaalala, auto trigger na sya."* **The boundary, decided by Neil 2026-08-10 — audience, not preference:** anything that OUTLIVES the conversation is **ENGLISH**: code and identifiers, commit **subject lines**, PR titles, GitHub issues, workflow docs, `NOW.md`, and every brief handed to `code-executor` / `codex-sol` (they get zero conversation context, and a Taglish spec fails *quietly*). Commit **bodies** may be Taglish. **Two carve-outs that never move: chat with Neil is Taglish, and customer-facing copy is Taglish** — the 98.5%-retention KM-003 hook is pure Tagalog. "Professional English" applies to the repo, never to the ads. This rule drifted for months because nothing enforced it and the agent wrote docs in whatever register it was chatting in. Follow his lead when he switches to English mid-thread. **Inside chat, the technical nouns stay English** — hook, retention, frame, syllable, build, lint, preset. The Tagalog is the frame and the connectors; do not translate a term he says in English. This is the opposite of the customer-copy rule, where English jargon is the defect. (2026-08-01, chat/copy split moved out of `NOW.md` 2026-08-10)
- **Don't assert time or date from inference — read it.** `date` is one shell call; the harness injects the DATE only, never the clock. Kept saying "ngayong gabi" through a 12:19 PM session because commit timestamps said 23:50/01:00 and "session close". Same failure class as trusting a stale doc over the code: a primary source was one command away. The SessionStart hook now prints local date+time for exactly this. Note the cafe PC reports **CST/GMT+0800**, same offset as Manila but not the PH zone — right number, wrong label. (2026-08-01)
- **Pick the register BEFORE writing any copy — and PURE TAGALOG IS NEVER IT.** Applies to all output: copy, marketing, sales, websites, ad scripts, captions, emails. Taglish when Taglish fits; **English when English fits, and then write it fully in English** — not Taglish wearing English words. Then tune the tone to the specific surface: a sales page, a UGC script, a nav label and a Messenger reply are different registers even when all four are Taglish. This recurred on Oceanides, scripting included. Encoded as STEP 0 in `_shared/taglish-voice.md`, which previously only taught *how* to write Taglish and silently assumed Taglish was always the answer. (2026-08-01)
- **ALL agent-authored Taglish follows `.claude/skills/_shared/taglish-voice.md`** — modern Taglish, never formal/deep Tagalog; typography rules included (no `'` in contractions: `nyo`/`yan`/`wag`; no em dash — use period or comma). TUNED prompts are out of scope — voice-driven changes there go through gated proposals. (2026-07-20)
- **User-facing Tagalog/Taglish copy: Sol or Gemini writes the first draft; Claude briefs, QAs against the tuned constraints, and assembles.** If Claude must write it (no Sol access), flag Neil for a native-ear pass before publishing. (2026-07-22)
- **Paid-ad creative — even agency-lane, outside the app — follows the tuned formula in `api/_lib/prompts.ts`** (hook word counts, body pacing, pattern-interrupt, APPEARANCE_LOCK / one-operator-one-jobsite); verify every structural claim against the TUNED files, not memory. `script-pool.json` is Lane A organic only. (2026-07-22)
- **Real-person creatives: a filename is a claim, not a fact.** Confirm identity against the canonical ref (Zam: `workflows/believability-samples/zam-ref-source.jpg`; the `assets/ad-samples/zam-*.png` files are MISLABELED — not Zam) or with Neil before putting a face on anything. (2026-07-15)
- **Poster/creative doctrine (Neil-set):** text never overlaps skin/face — type sits on dark clothing or dark negative space (cream canvas → dress the subject in black; the wardrobe IS the text panel); text always high-contrast (no mid-gray body copy on any canvas); backgrounds are noir (zinc-950 grain) or cream `#F2F1EA` ONLY, unless the format is photo-native UGC; export @2x lossless. (2026-07-15)

## Repo gotchas (one-liners)

- ⛔ **Never drop a file into `public/`** unless you intend the whole internet to have it — Vite copies that directory verbatim into `dist/`, so anything there is served from `grifon.ai` at a guessable path. Happened 2026-08-10 with `motion-promo.skill`; moved to `workflows/assets/`. Repo-internal assets, skills, and working files go anywhere BUT `public/`. (2026-08-10)
- **Never `git add -A` while a smoke agent is running** — the subagent's throwaway scripts land in your commit (bit us 2026-08-08). Stage explicit paths when any agent is live.

- New `api/**/[param].ts` route → smoke it in `npm run dev`, not just Vercel preview (dev-plugin resolver parity). (2026-05-04)
- `.env` edit not sticking → fully kill node + restart; don't trust Vite's "server restarted" message. (2026-05-04)
- Veo 429 mid-RENDER-ALL is BY DESIGN (hourly per-key cap) — the queue auto-resumes; never add a manual retry button. (2026-05-13)
- `position: fixed` clamped to a parent box → an ancestor has `backdrop-filter`/`transform`/`filter`; portal to `document.body`. Use `overflow-x: clip`, not `hidden`, to keep `sticky` alive. (2026-05-30)
- ffmpeg: run with `cwd` + bare filenames (no drive colons in filtergraphs); single-quote expression values; `drawbox` is eval-once (animate via `enable`-gated slices) but `drawtext` fontsize/y/alpha animate per-frame; any dynamic scale chain ends `,setsar=1`; verify motion via frames inside the animation window. (2026-06-08, 2026-06-10)
- OTP flows: Supabase dashboard Email OTP Length must equal the UI's hardcoded 6 — console-config bugs only surface in live smokes, never CI. (2026-06-30)
- Post-defreeze ritual: repo-local `git config user.email/user.name`; `scripts/restore-gh.ps1` then `gh auth login` run to the "✓ Logged in" line (browser-authorize alone writes nothing; a stale `GH_TOKEN` env var silently overrides a good keyring login). (2026-06-10, 2026-06-30)
- Never hand-transcribe brand-mark SVGs (copy canonical paths); federated OAuth buttons go on neutral surfaces, never brand gold; bold/uppercase text pairs with `w-5` icon + 12px gap. (2026-05-26)
- SigV4 GET-signed URLs always 403 on HEAD (method is in the canonical request) — probe with a ranged GET; Meta's auto video thumbnail is frame 0, so frame-0 must carry the hook overlay or ship an explicit thumbnail. (2026-07-27)
- Meta System User names containing "Ads"/"API" are silently invalid; the app asset permission must be `Manage app` (full access), not `Develop app`. Runbook: `workflows/infra_setup.md` §7. (2026-07-27)
- A session banner saying an MCP server "requires authentication" is not proof it is dead — Neil's claude.ai connectors were authorized and worked on the first call while the banner claimed otherwise. TRY the tool (load schema via ToolSearch, one cheap read call) before telling Neil a capability is unavailable. (2026-08-03)
- **Ang basura ng render ay tumatambak nang mabilis at hindi mo napapansin** — isang session ng KM-004 ang nag-iwan ng 87 MB, at 117 MB pa ang natagpuan sa lumang KM-002 pilot. **Naka-hook na sya, hindi na inaalala: [`tools/ad_asset_sweep.mjs`](tools/ad_asset_sweep.mjs)** sa SessionStart. Awtomatikong binubura ang `ads/*/edit/` (gitignored, deklaradong rebuildable) at **isinusumbong lang** ang iba — supersedeng `-vN.mp4`, litratong may katabing `.mp4` at recipe, at overlay na hindi tinutukoy ng `build-cut.sh`. Sinasadya ang hati: ang isang Veo clip ay BAYAD at hindi na maibabalik kapag ubos ang budget, kaya ang bulag na pagbura ay mas mahal kaysa sa tambak. `--apply` kapag sang-ayon na ang mata. (2026-08-03)
- 🔴 **A flag the money-gate treats as free must actually BE free in the rig.** `veo-render-gate.sh` waved through any command containing `--dry-run` uncounted — but `veo-produce.mjs` never implemented the flag, silently ignored it, and submitted a real paid call. I fell through the hole myself while diagnosing a failure I thought I was inspecting for free. When a gate exempts a flag, grep the target script for that flag in the same breath. (2026-08-03)
- **`has_payment_method` from Meta's `ads_get_ad_accounts` is unreliable** — reported `false` for an account that was Active with a Visa on file. Same class as the MCP auth banner below: a field is a claim, not evidence. Neil's Billing screen wins; do not re-raise a payment doubt he has already answered. (2026-08-03)
- **No `bc` on the cafe PC, and it fails SILENTLY inside a build script** — the substitution comes back empty, the ffmpeg expression becomes `on/(-1)`, and the whole punch-in vanishes while the build still reports success. Use `awk "BEGIN{printf ...}"` for shell arithmetic. Same shape as the fontfile footgun: the build looked like an answer. (2026-08-03)
- **A funnel under `funnels/*` has its OWN `node_modules`** — the defreezer eats it and the build dies on a missing `@fontsource/*` long before it reaches your code. `npm ci` inside the funnel dir first; its lock is separate from the root one, so the root package-lock rule does not apply. (2026-08-03)
- Meta Events Manager aggregate stats lag ~1h behind the pixel fire — a just-submitted test Lead is absent from `ads_get_dataset_stats` while being fully real. Network-level `/tr?ev=Lead` count is the ground truth for fire-count checks (0 on load / 1 on submit); re-poll the dataset later for the paper trail. (2026-08-03)
